# Finans

Kişisel harcama / gelir takibi. İş Bankası kart ekstresi (PDF) ve hesap hareketleri (.xls) yüklenir; veriler sadece cihazdaki tarayıcıda (IndexedDB) tutulur, hiçbir sunucuya gönderilmez.

- `npm run dev` — geliştirme
- `npm test` — testler (gerçek ekstreler `fixtures-private/` altında, repoya girmez)
- `npm run build` — PWA derlemesi (GitHub Pages'e otomatik yayınlanır)
